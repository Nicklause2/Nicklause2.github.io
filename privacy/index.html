Privacy policy

Personal Encrypted Vault Backup is an independent personal application maintained by Nicklause2 for the owner's own vault backups. It is not offered as a public service.

Google data access and use

The application requests https://www.googleapis.com/auth/drive.file. This permission covers files and folders created by the app, or explicitly opened or shared with it. The application uses it to create backup storage, upload encrypted archives and download those archives to verify their integrity.

The application processes encrypted archive bytes and operational metadata such as file names, identifiers, sizes and checksums. It stores OAuth access and refresh tokens to maintain the owner's authorized connection. It does not request access to Gmail, contacts or calendars, or unrestricted access to all Drive files.

Vault data and encryption

Vault backups are encrypted on the owner's private system before upload. No plaintext vault archive is uploaded to Google Drive or this website. Backup creation and verification process recovered data in memory; an isolated application recovery test uses temporary storage on the private system that is configured not to swap.

The long-term recovery private key is kept outside the backup server. Routine verification uses a separate random, per-archive secret held temporarily in memory and not retained. The public website receives no vault contents, recovery private keys or passphrases.

Storage and safeguards

Encrypted archives are kept in the owner's private backup storage and Google Drive. Connection credentials are stored in a restricted configuration on the owner's private backup system. Access is limited to the backup process and its administrator. This website contains no backup downloads, authentication credentials or private service addresses.

Sharing and service providers

Google receives the encrypted backup files and related Drive metadata to provide storage and retrieval. The application does not sell Google user data or use it for advertising, profiling or training machine-learning models. It does not share backup data with unrelated third parties.

GitHub hosts this public information website. GitHub documents that GitHub Pages logs visitor IP addresses for security purposes. The site adds no analytics scripts, advertising, forms or application cookies. See the GitHub Privacy Statement and Google Privacy Policy for their respective practices.

Retention, deletion and revocation

Dated encrypted backups are retained until the owner chooses to remove them; the application currently has no automatic deletion policy. The owner controls the backup files in their own storage and Drive account.

The owner can stop the backup schedule and revoke the application's access in Google Account connections. Revocation stops future authorized access; it does not by itself delete existing backup files. The owner or administrator must separately remove any unwanted archives or saved connection configuration.

Limited use

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Access is used only to provide the owner's requested backup and recovery functionality.

Contact and changes

Use the support email displayed on the application's Google consent screen for privacy or access questions. Do not send passwords, private keys or vault exports. This policy will be updated if the application's data practices change.
