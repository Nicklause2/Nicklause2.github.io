Personal use · Encrypted backups

A private recovery plan.
A small public explanation.

This independent personal application stores encrypted backups of its owner's Bitwarden vault in the owner's Google Drive and downloads them to check recoverability.

What the application does

  1. Encrypt before upload. The backup is encrypted on the owner's private system using a public recovery key.
  2. Store a dated copy. Only verified encrypted archives are uploaded to the owner's Google Drive.
  3. Check the stored copy. The application downloads the encrypted file, compares it with the original and verifies its archive and database integrity.

The private recovery key is kept outside the backup server. The owner separately tests recovery with their own protected key copies.

Why Google access is requested

The application uses Google Drive's drive.file permission to create and manage its backup files and folders and download them for verification. That permission applies to files created by the app or explicitly opened or shared with it; it does not grant unrestricted access to every file in Drive.

Google authorization happens through Google's own consent flow. This website has no sign-in form and collects no passwords, vault contents, recovery keys or Google credentials.

For the owner only

This is documentation for a personal integration, not a public backup service. No vault or server endpoint is published here. The application is not operated by or affiliated with Bitwarden or Google.
